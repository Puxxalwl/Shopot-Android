# Stille Messenger (Android)

**English** | [Русский](ru/README.md)

Android-клиент для демона [shopot-core](https://github.com/Puxxalwl/shopot-core).

## Возможности
- **P2P — без серверов** — прямой TCP (порты 7777–7786), LAN discovery или self-hosted relay
- **Сквозное шифрование (E2EE)** — клиент никогда не работает с ключами
- **Без телеметрии, аналитики, Firebase**
- **Glassmorphism UI** — iPhone-стиль с размытием фона
- **Богатые сообщения** — bold, italic, spoiler, code, links
- **Реакции** — любой Unicode эмодзи
- **Файлы и фото** — до 64 МБ
- **Голосовые звонки** — 16 кГц E2EE, ADPCM + DTX
- **Офлайн-доставка** — зашифрованный outbox с ACK и dedup

## Первый запуск

При первом запуске Stille Messenger показывает локальное окно настройки: язык
интерфейса, системная/светлая/тёмная тема и имя, отображаемое в профиле.
Выборы хранятся на устройстве и доступны для изменения позже в приложении.


Stille — «тишина» по-немецки. Имя ограничено 1–32 байтами UTF-8, как в ядре
(16 русских букв или 8 четырёхбайтовых emoji). Кнопка «Продолжить» находится
внизу, форма прокручивается. Android application ID изменён на `com.stille.messenger`: отдельная установка без автоматического переноса старых данных.

## Навигация

Переключайте Профиль, Чаты, Контакты и Настройки горизонтальными свайпами или
нижними вкладками. Переходы используют плавный сдвиг с лёгкой имитацией motion
blur на Android 12+; на старых устройствах — сдвиг, масштабирование и затухание
без blur. В покое содержимое чёткое. В разговоре и листе приглашений свайпы
разделов отключены. «Назад» из разговора возвращает в исходный раздел.

## Фото профиля

В профиле нажмите **Установить фото** / **Изменить фото**. Системный выборщик не
требует общего доступа к хранилищу. Изображения до 8 МиБ обрабатываются вне UI:
учёт EXIF-ориентации, квадратная обрезка по центру, JPEG без метаданных,
уменьшение и сжатие до лимита ядра 16 000 байт. Успех показывается только после
подтверждения id содержимого и размера через SET_AVATAR. При ошибке остаётся
прежнее фото.

Профиль, чаты и контакты показывают фото из памяти, при отсутствии — инициалы.
Кеш ограничен 20 изображениями, включая своё; фото собеседника требует
подтверждённого JOIN. Ядро хранит загруженное фото зашифрованно между запусками.
**Ограничение текущего API:** метода чтения байтов собственного фото нет,
поэтому свой предпросмотр доступен только пока его хранит процесс сервиса.
Фото собеседников приходят через AVATAR_RECEIVED; клиент не опрашивает ядро
и не пишет незашифрованный кеш. Съёмка камерой, ручной редактор обрезки и
API удаления фото не реализованы.

## Сборка

```bash
# 1. Сборка shopot-core для Android (требует Zig 0.17.0)
./tools/build-core.sh

# 2. Сборка Android-приложения
./gradlew :app:assembleDebug

# 3. Тесты
./gradlew :data:testDebugUnitTest :app:testDebugUnitTest

# Быстрая инкрементальная проверка Kotlin (сохраняет daemon Gradle/Kotlin)
./gradlew :app:compileDebugKotlin --daemon --offline --max-workers=2
```

**Требования:** Android 8.0+ (API 26), JDK 17, Zig 0.17.0 для сборки core.

## Linux-клиент

Официальный Linux-клиент — [EryyynIT/shopot](https://github.com/EryyynIT/shopot).
Он использует тот же shopot-core и бинарный UDS API, поэтому служит
референсом desktop UX и интеграции.

## Архитектура

```
app/                      # Android-приложение: UI + foreground service
data/                     # Кодек бинарного протокола (соответствует CORE-API.md)
core-src/                 # Исходники shopot-core (cloned)
tools/                    # Скрипты кросс-компиляции
```

`StilleService` — foreground service, который:
1. Распаковывает и запускает бинарник `shopot` из assets
2. Подключается к UDS `$HOME/.shopot/api.sock`
3. Отправляет `GET_VERSION` для проверки совместимости
4. Слушает события и рассылает их в UI через `StateFlow`

## Добавление друга

Откройте приглашение из раздела «Чаты» или «Контакты». Stille создаёт одноразовый
код через бинарный API `CREATE_INVITE` и хранит его только в памяти. Ссылку можно
скопировать, отправить системным меню Android или показать чёрно-белым QR с
символом Stille без надписи. Получатель вставляет ссылку или выбирает изображение
QR; Stille принимает его через `ACCEPT_INVITE` и показывает контакт только после
доверенного события `CONTACT_JOINED`.

```
A: CREATE_INVITE → "shopot://i/ABC123..."
   (делимся в любом мессенджере или через QR)
B: ACCEPT_INVITE → ждём CONTACT_JOINED → соединение установлено
```
