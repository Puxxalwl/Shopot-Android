# Кодекс поведения участников

[English](../CODE_OF_CONDUCT.md) | **Русский**

## Наше обещание

Мы — участники, контрибьюторы и лидеры — обещаем, что участие в нашем
сообществе будет свободным от домогательств опытом для каждого.

## Наши стандарты

Примеры поведения, укрепляющего сообщество:
- Уважение к иному мнению
- Открытость к новичкам
- Принятие конструктивной критики

## Сообщение о нарушении

Сообщайте через приватную вкладку GitHub *Security → Report a
vulnerability* или личным сообщением в профиль мейнтейнера на GitHub.
