# Правила документации (RU)

**English** | [Русский](ru/DOCS.md)

Это зеркало `DOCS.md`. Обновляется в том же коммите, что и английская версия.

## 1. Языки
- EN нормативный (корень репо).
- RU зеркала в `ru/`.

## 2. Голос
- Технический, фактологичный. Без маркетинга.

## 3. Факты из кода
- Все размеры, константы, пути проверяются против исходников.

## 4. Структура
- Таблицы для машинных контрактов.
- Одна таблица лимитов на документ.

## 5. Нотация
- `u8`/`u16`/`u32`/`u64` — целые числа.
- `str16`/`str32` = `[len u16|u32][bytes]` (UTF-8, без нулевого терминатора).
- Hex с префиксом `0x` для констант.

## 7. Change discipline
- Изменение протокола требует обновления кодека и CHANGELOG.md в одном коммите.
