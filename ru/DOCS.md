# Правила документации

[English](../DOCS.md) | **Русский**

Обязательные правила написания и изменения документации в этом
репозитории. Зеркалируют `docs/DOCSTYLE.md` из stille-messenger-core и
имеют ту же силу. Нарушение блокирует ревью.

## 1. Языки и расположение

- **Английский — нормативная версия**: корень `README.md`, `AGENTS.md`,
  `CONTRIBUTING.md`, `DOCS.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md` и
  `docs/*.md`.
- **Русские зеркала живут в `ru/`**: `ru/README.md`, `ru/USAGE.md`, … —
  то же имя файла, без суффикса `.ru`; язык несёт каталог.
- Каждый документ начинается строкой переключателя языка со ссылкой на
  зеркало; работать должны оба направления.
- EN и RU не расходятся: изменение одного попадает в другое **тем же
  коммитом**. Отставание перевода — баг.

## 2. Карта документов

| Документ | Владеет |
|---|---|
| `README.md` | Идентичность, сводка возможностей, индекс документации, быстрый старт |
| `docs/USAGE.md` | Поведение приложения для пользователя |
| `docs/BUILD.md` | Сборка, тесты, подпись, публикация |
| `docs/ARCHITECTURE.md` | Устройство клиента, граница с ядром, инварианты |
| `docs/RECOVERY.md` | Церемония восстановления, блоб, хранилища |
| `docs/UI-DESIGN.md` | Визуальное и интерактивное направление |

Одна тема — один дом. Остальные документы ссылаются на него, а не
пересказывают.

## 3. Голос

- Нормативный и технический. Без маркетинга, без заполнителя, без
  «просто», «легко», без восклицательных знаков.
- Только факты, настоящее время, активный залог. Описывайте то, что код
  делает сегодня.
- Каждый документ называет аудиторию в первых двух строках
  (пользователи / контрибьюторы / разработчики клиентов).

## 4. Факты из кода

- Каждый layout байтов, константа, лимит, числовой код и путь
  проверяются против `core-src/core/docs/CORE-API.md` и кодека протокола
  `data/src/main/java/com/stille/coreapi/`.
- Код и документация расходятся → одно из них неверно. Исправьте оба
  одним коммитом или заведите issue.
- Документ никогда не описывает поведение, которого нет в реализации.

## 5. Структура

- Layout байтов — в fenced code blocks.
- Машинные контракты (статусы, методы, события): таблица с числовым
  значением + SCREAMING_SNAKE-именем + условием появления.
- Одна каноническая таблица лимитов на документ, из `CORE-API.md` §6.
- Честные ограничения: указывайте, что не покрыто.

## 6. Нотация

- `u8`/`u16`/`u32`/`u64` — целые без знака.
- `str16`/`str32` = `[len u16|u32][bytes]` (UTF-8, без нулевого
  терминатора).
- Hex с префиксом `0x` для констант.

## 7. Дисциплина изменений

- Изменение протокола требует обновления кодека и `CHANGELOG.md` одним
  коммитом.
- Видимые пользователю изменения обновляют соответствующую страницу
  `docs/` и её RU-зеркало.
