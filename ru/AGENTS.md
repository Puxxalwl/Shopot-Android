# AGENTS.md — клиент Stille-Messenger

[English](../AGENTS.md) | **Русский**

*(Русское зеркало AGENTS.md. Обновляется тем же коммитом, что и английская
версия.)*

Этот файл — контракт для контрибьюторов, ИИ-агентов и ревьюеров. Он
адаптирует `AGENTS.md` из stille-messenger-core к Android-клиенту. Клиент
**никогда** не владеет решениями о криптографии, протоколе или формате
хранения — они живут в stille-messenger-core. Задача клиента — рендеринг
и транспортный клей.

## 1. Инварианты
1. Без собственных серверов, телеметрии, аналитики, crash-репортёров.
   Клиент подключается только к локальному демону
   `stille-messenger-core serve` по UDS.
2. Минимум зависимостей: Kotlin + Compose + Hilt + Coil, плюс
   `androidx.credentials` только для passkey-восстановления аккаунта.
   Каждая новая зависимость требует обоснования в `CHANGELOG.md` и не
   касается криптографии.
3. Нет plaintext на диске.
4. Только бинарный протокол (UDS).
5. Аутентификация перед доверием: имя, личность и аватар контакта —
   только после события `CONTACT_JOINED`.
6. Ограниченные ресурсы (кеш ≤ 200 сообщений, ≤ 20 аватаров,
   ≤ 50 МБ файлов). Временный проверенный APK из GitHub Releases может
   храниться в приватном кеше для подтверждённой пользователем установки.
7. Корректность важнее скорости: без пропуска валидации фреймов,
   проверок последовательности и дедупа message-id.
8. Главный поток отзывчив: весь UDS I/O — вне потока; UI собирает
   `StateFlow` из foreground-сервиса.

## 2. Источник правды
- Активная реализация stille-messenger-core — в `core-src/core/`.
- Клиент должен следить за `CORE-API.md`; кодек `StilleProtocol.kt`
  совпадает с ним байт в байт.
- Документация: карта `docs/` и правила — в `DOCS.md`; EN нормативен,
  RU-зеркала обновляются тем же коммитом.
